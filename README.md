# 四时木 · Four Seasons Tree

微信小程序中的 WebGL / Three.js 三维树：春季发芽开花、夏季繁叶、秋季落叶、冬季飘雪与积雪。时间轴连续插值，自动播放一轮为 48 秒；拖动时间轴会暂停播放。单指拖动画布旋转视角，双指缩放。

## 树种、生长与环境

内置樱花、日本红枫、银杏、美国枫香、紫薇、柿子树、落羽杉、水杉、白桦、梅花、玉兰与栾树。树种各自拥有树冠形态、叶形、季节叶色、花期和果期：例如银杏扇叶转金黄、梅花冬季开花、紫薇夏花、柿子落叶挂果、白桦白色树干、枫香冬季果球和玉兰枝芽。

在树种选择旁展开“生长与环境”即可调整：

- **生长**：种子 → 萌芽 → 幼树 → 成树 → 老树，枝条逐步展开，树冠和树干随阶段变化。自动生长约 90 秒，到老树后停止，再播放从种子重新开始。
- **昼夜**：手动选择 24 小时中的时间，或开启约 120 秒一轮的循环；日出日落改变光线方向和天空颜色，夜间出现星空与月亮。
- **天气**：随季节 / 晴天 / 雨 / 雪，以及雨雪强度。手动天气覆盖季节降雪，转晴后积雪逐渐融化。
- **光照**：强度 0–150%，改变环境光和方向光。

四季、生长、昼夜独立播放；拖动某条时间轴只暂停对应时钟。切换树种保留这些参数。新增控制采用风格化表现，生长进度不对应真实年数；本次未将新增参数接入云端保存。

## 开发与运行

```sh
npm ci
npm run type-check
npm test
```

在微信开发者工具中导入项目根目录，打开 `pages/season-tree/index`。`npm run build` 编译 TypeScript，并将小程序适配引擎及许可证复制到 `miniprogram/vendor/`，无需再手动“构建 npm”。编译后的 `.js`、`.js.map` 和引擎文件保留在小程序目录，供预览和上传使用。

浏览器中的本地验证入口：

```sh
npm run preview
```

打开 <http://127.0.0.1:4173>。它运行同一套场景代码，通过独立的 Canvas 桥接模拟微信节点；滚轮也可缩放。该入口用于检查图形和交互，不能替代微信开发者工具与 iOS / Android 真机验证。

## 渲染与生命周期

- 页面只传入原生 `type="webgl"` Canvas、季节进度和触摸操作；每帧动画不进入 `data`。
- `TreePresets` 定义 12 种树木；`SeasonController`、`GrowthController` 和 `EnvironmentController` 分别计算季节、生长与环境状态；`TreeTrunk` 用固定种子生成三维骨架，所有枝叶、花果共用生长和摆动坐标。
- `BranchSystem` 合并曲面枝干；`MeshBatch` 合并叶片、花瓣和粒子，适用于 WebGL 1，无需实例化扩展或外部纹理。天空用渐变着色器，光照使用半球光与方向光。
- 相机按画布实际尺寸适配；DPR 上限为 2，帧时间步长上限为 50ms。页面隐藏停止动画，卸载释放几何、材质、渲染器与上下文；初始化失败可用新画布节点重试。
- 大幅跳转季节会清理旧粒子，避免冬季雪花带入夏季。落地叶片数量有上限，并随时间衰减。
- 批量网格复用面法线模板，只计算与上传当前可见顶点；枝干复用环面角度，普通树皮颜色不随摆动重复上传。未变化的生长骨架、积雪几何和 HUD 状态会跳过重复更新。

构建后运行 `node scripts/benchmark-render.cjs` 可检查 6 个代表场景的几何更新 CPU 耗时和后续缓冲区上传量估算。固定随机种子，预热 120 帧，每组测量 180 帧、取 5 组中位数；不包含 GPU 绘制、首次缓冲区分配或小程序页面通信。优化前后数据及验证边界见 [渲染性能记录](docs/render-performance.md)。

## 适配约束

运行时固定使用微信维护的 [`threejs-miniprogram@0.0.8`](https://github.com/wechat-miniprogram/threejs-miniprogram)，内置 Three.js **r108**。`three@0.108.0` 仅作为开发依赖，提供与适配引擎一致的类型和测试环境，运行时没有导入浏览器版 Three.js。

升级引擎版本必须同时验证小程序 WebGL、Canvas 作用域、资源释放及类型兼容。当前实现使用程序化几何，不加载模型或远程素材。真实设备仍需验证手势、前后台切换、横竖屏切换及长时间播放的帧率与内存。

详细架构决定见 [渲染迁移记录](docs/adr/001-webgl-rendering.md)。
树种与环境的状态边界见 [树种、生长与环境记录](docs/adr/002-species-growth-environment.md)。
